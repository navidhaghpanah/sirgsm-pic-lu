# Sirgsm Pic Lu — جستجوی هوشمند عکس‌ها (AI Local Image Search)

**ساخته‌شده توسط:** NH  
**اسپانسر:** [sirgsm.ir](https://sirgsm.ir)

این برنامه با استفاده از هوش مصنوعی (**CLIP Multilingual**) محتوای عکس‌های داخل سیستم شما را می‌فهمد و به شما امکان می‌دهد با جستجوی کلمات و عباراتی مثل **«دریا»**، **«کوه»**، **«گربه»**، **«ماشین قرمز»** یا **«sunset»** عکس‌های مرتبط را پیدا کنید — حتی اگر نام فایل‌ها کاملاً بی‌ربط باشد.

## ویژگی‌های کلیدی
- **پشتیبانی از فارسی، انگلیسی و بیش از ۵۰ زبان** با مدل چندزبانه CLIP.
- **مصرف رم بسیار پایین در پوشه‌های بزرگ:** پردازش دسته‌ای (Batch Streaming) و آزادسازی خودکار مدل تصویر پس از ایندکس (مناسب برای هزاران عکس بدون پر شدن رم).
- **کش افزایشی هوشمند و امن:** در ایندکس مجدد پوشه، فقط عکس‌های جدید یا تغییریافته پردازش می‌شوند.
- **کاملاً آفلاین و خصوصی:** پس از اولین دانلود مدل‌ها، برنامه بدون نیاز به اینترنت و ۱۰۰٪ روی سیستم خودتان اجرا می‌شود.
- **پیش‌نمایش سریع (Thumbnail)، نوار پیشرفت زنده، انتخابگر پوشه و نمایش مستقیم فایل در پوشه.**

## اجرای نسخه پرتابل ویندوز (بدون نیاز به نصب پایتون)
1. فایل `Sirgsm-Pic-Lu-Windows-Portable.zip` را استخراج (Extract) کنید.
2. فایل `Sirgsm-Pic-Lu.exe` را اجرا کنید؛ مرورگر به‌صورت خودکار باز می‌شود.
   - *نکته ویندوز:* در صورت عدم نصب بودن پیش‌نیاز مایکروسافت روی ویندوزهای تازه نصب‌شده، بسته [Microsoft Visual C++ Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe) را نصب کنید.
   - *حالت کاملاً پرتابل روی فلش:* اگر یک پوشه به نام `models` کنار فایل `Sirgsm-Pic-Lu.exe` بسازید، مدل‌های هوش مصنوعی مستقیماً داخل همان پوشه ذخیره و خوانده می‌شوند.

---

## نصب و اجرا از سورس پایتون

### پیش‌نیازها
- پایتون **3.10 تا 3.12** (نسخه ۶۴ بیتی توصیه می‌شود)

### مراحل راه‌اندازی

1. (پیشنهادی) نصب نسخه سبک PyTorch مخصوص CPU برای کاهش حجم دانلود از ~۲.۵ گیگابایت به ~۱۸۰ مگابایت:
   ```bash
   pip install "torch==2.8.0" --index-url https://download.pytorch.org/whl/cpu
   ```
   *(اگر کارت گرافیک NVIDIA دارید و می‌خواهید از شتاب‌دهنده CUDA استفاده کنید، می‌توانید نسخه CUDA پای‌تورچ ۲.۸ را نصب کنید؛ برنامه به‌صورت خودکار GPU را تشخیص می‌دهد.)*

2. نصب سایر کتابخانه‌ها:
   ```bash
   pip install -r requirements.txt
   ```

3. اجرای برنامه:
   ```bash
   python app.py
   ```
   مرورگر به‌صورت خودکار روی `http://127.0.0.1:8000` (یا اولین پورت آزاد بعدی) باز می‌شود.

## نحوه استفاده
1. در کادر اول، روی **انتخاب پوشه…** کلیک کنید یا مسیر پوشه عکس‌های خود را وارد نمایید (مثلاً `C:\Users\YourName\Pictures` در ویندوز یا `~/Pictures` در مک/لینوکس) و دکمه **ایندکس پوشه** را بزنید.
   - *نکته:* فقط در **اولین اجرا** مدل هوش مصنوعی دانلود می‌شود (در صورت محدودیت دسترسی به HuggingFace، اتصال تغییر IP یا تنظیم متغیر محیطی `HF_ENDPOINT` لازم است). پس از آن برنامه کاملاً آفلاین کار می‌کند.
   - با فعال کردن گزینه **«افزودن به پوشه‌های قبلی»** می‌توانید چندین پوشه مختلف را همزمان در ایندکس نگه دارید.
2. در کادر جستجو، عبارت مورد نظر را به فارسی یا انگلیسی بنویسید (مثلاً `دریا و غروب`) و **جستجو** را بزنید.
3. با کلیک روی هر عکس، تصویر با کیفیت اصلی باز می‌شود و می‌توانید مسیر آن را کپی کنید یا مستقیماً محل فایل را در ویندوز باز نمایید.

## ساخت فایل EXE پرتابل ویندوز

### روش اول: در ویندوز (محلی)
- ساخت نسخه پرتابل سریع (پوشه + فایل ZIP — **پیشنهادی**، اجرای ۱ تا ۲ ثانیه‌ای):
  ```bat
  build_portable.bat
  ```
- ساخت نسخه تک‌فایل (`Sirgsm-Pic-Lu.exe`):
  ```bat
  build_portable.bat --onefile
  ```

### روش دوم: خودکار با GitHub Actions
با Push کردن پروژه در گیت‌هاب (شاخه `main` یا `master`) یا اجرای دستی از تب **Actions**، فایل پرتابل ویندوز به‌صورت خودکار ساخته، تست (`--self-test`) و در بخش **Artifacts** آپلود می‌شود. همچنین با ثبت تگ نسخه (مثل `v1.0.0`)، به‌صورت خودکار در بخش **Releases** منتشر می‌گردد.
